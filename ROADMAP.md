# Roadmap & Task Breakdown

The POC is divided into discrete tasks that map to the customer vision for Azure-centric AI agents handling cloud infrastructure and cybersecurity automation.

- [x] **Architecture definition** – Produce C4 diagrams describing the Azure-first AI/ML topology and controls.
- [x] **Data ingestion and embedding pipeline** – Implement a lightweight ingestion + vectorization flow to simulate RAG-ready content.
- [x] **Threat classification engine** – Build a rule-based classifier for cybersecurity incidents with prioritization logic and explainable evidence.
- [x] **Agentic chatbot core** – Provide a multi-turn agent that retrieves context, classifies threats, and proposes remediation steps.
- [x] **Enterprise integration stubs** – Model REST-friendly connectors for ConnectWise/Confluence-like systems with auditing.
- [x] **Compliance logging** – Centralize audit trail generation for AI decisions and actions.
- [x] **Test coverage** – Add unit tests validating pipelines, classification, and agent orchestration behaviour.
